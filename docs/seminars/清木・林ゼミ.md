## 研究テーマ：行動データマイニング
- サイバー・フィジカル空間における **「行動の理解」「心の推定」「環境創出」** のための行動データマイニング研究を行う。
- 人間の行動（**移動 → 滞在 → 活動**）には、その人の目的・関心・感情・身体状態・周囲の環境など、さまざまな情報が表れる。センサ・カメラ・スマートフォン・情報システムなどから得られる行動データを分析し、人間の行動を理解するとともに、その背景にある心や状態を推定する。
- さらに、分析・推定結果を人間や環境へフィードバックすることで、より良い**自然環境・社会環境・バーチャル空間・教育／学習環境**を創り出すことを目指す。
- 現実世界と情報空間が相互に接続されたサイバー・フィジカル空間を前提として、**センシング → データ管理 → 分析・推定 → 可視化 → フィードバック**までを一体的に扱う。

## 4つの柱（Research Pillars）
「行動の理解」「心の推定」「環境創出」を実現するため、次の4つの柱に基づいて研究・開発・教育を進めている。

1. **Behavioral Data Analytics towards Mindfulness Computing（マインドフルネス・コンピューティングに向けた行動データ分析）**
   - 行動、身体状態、感情、認知状態、周囲の状況に関するデータから、集中・緊張・疲労・関心・感情・習慣などを推定する。結果を本人へ分かりやすく提示し、気づき、振り返り、自己理解、行動変容を支援するコンピューティングを研究する。
2. **Spatio-Temporal Analysis for Environment Creation（より良い環境創出のための時空間データ分析）**
   - 人流、移動、滞在、混雑、環境変化、学習活動、オンライン行動などを対象として、場所と時間に依存するパターンや関係性を発見する。自然環境・社会環境・バーチャル空間・教育／学習空間をより良く設計するために分析結果を活用する。
3. **Sensing Devices & Dashboards（センシング機器とダッシュボードの研究開発）**
   - センサ、カメラ、スマートフォン、ウェアラブルデバイスなどを用いて人間や環境の状態を取得する。収集データとAIによる分析結果を統合し、利用者が状況を直感的に理解できるダッシュボード・通知・フィードバック機構を研究開発する。
4. **AI & Database Education（AI・データベース分野の人材育成）**
   - AIやデータベースを利用するだけでなく、現実の問題を計算可能な形で捉え、独自のモデルやシステムを設計・実装できる人材を育成する。学生は研究テーマの設定、設計、実装、評価、発表を反復し、アイデアを実際に動作するシステムへ発展させる。

## 研究の観点（Viewpoints）
研究を進めるにあたり、次の観点を明確化し、議論と実装を反復しながら探求する。

- **データサイエンスとは**：対象領域における多様な事象に「計算の枠組み（実体とその属性、実体間の関係性、計算方式）」を与え、課題解決と新たな価値創造を可能にする知の体系化とその探求。概念設計・情報モデリングとも呼ばれる。
- **人工知能とは**：「知能」＝自律性と適応性を備えるもの。AIも固定的な定義はなく、人間の知的活動を模倣・実現する理論・技術・システムの総称。大規模言語モデルに限られない。
- **独自の中核計算の設計の必要性**：一般的なAIは精度向上に議論が偏りがちだが、計算モデルが領域の目的に照らして妥当か、制約・文脈・安全性を組み込めるか、ブラックボックスを回避できるかが本質。既存手法の適用は出発点にすぎず、目的に整合した独自の中核計算を設計してはじめて新たな価値創造が可能になる。
- **システムアーキテクチャとは**：システムを構成する要素（モジュール・データ・計算・入出力・通信）とその関係・境界・責務を定め、データ構造（オペランド）とアルゴリズム（オペレータ）の対応を規定する設計原理。
- **知識ベースとは**：専門知（概念・定義・因果関係・手順・制約・文脈）を計算機が参照・推論・検証できる形（オントロジ、知識グラフ、ルール、制約条件、確率モデル等）で体系化した情報資源。
- **課題解決と新たな価値創造の違い**：課題解決は既存の目標・制約・評価基準の枠内で問題を特定し解を与える営み。新たな価値創造は望ましい未来像（ビジョン）から逆算し、「当たり前」や「常識」を問い直して領域のルールや体験を再設計する営み。
- **学際の必要性**：現代のグローバル課題は社会・環境・技術が相互依存し、単一分野では全体像の把握が困難。データ科学・工学・社会科学・人文知を横断する学際的アプローチが求められる。
- **計算方式とシステム実装の違い**：計算方式は「何を推定・予測・最適化するか」という計算の原理を定める設計。システム実装はそれを性能・信頼性・セキュリティ・運用などの現実の制約下で動作させる作業。
- **有効性と実現可能性**：有効性は設定した目的・課題に実際に効果を生み、既存手法より望ましい結果を示す性質。実現可能性は現実の制約を踏まえて実装・運用できる見込み。

## 未来創造プロジェクトと4年間の計画
1年生秋学期から始まる研究実践プログラム。履修者は自ら研究テーマを設定し、議論と実装のサイクルを反復して研究を深化させる。

| 年次 | テーマ | 内容 |
| --- | --- | --- |
| 1年次 | 基礎構築と研究テーマの設定 | 研究テーマを設定し問題意識を持つ。プロトタイプ開発に必要なシステムアーキテクチャ・データベース・プログラミングの基本概念を習得。 |
| 2年次 | モデル開発とプロトタイピング | 独自の計算モデルの設計・構築。提案モデルを実装しプロトタイプ開発に取り組む。 |
| 3年次 | モデルの改良と研究の拡大 | 既存の計算モデル・プロトタイプの改良・最適化。4年次の卒業研究テーマを設定し発展的な研究計画を立てる。学会発表を目標。 |
| 4年次 | 研究の完了と実世界への応用 | 卒業研究を進め成果を学術論文にまとめる。学会発表を行い社会実装の可能性を探る。 |

## 必要とされる知識・技能・マインドセット
- 概念設計・論理設計、データベースとSQL、プログラミングを基盤に、数学・統計・最適化による数理モデリング力を養う。
- ソフトウェアに加え、センサ・ネットワーク・サーバ・アクチュエータまでの実装を重視し、サイバーとフィジカルの接続を実現する。
- 目的・意味・概念を哲学的に問い直す姿勢と、独自の中核計算を設計しようとする探究心。自ら学び続け、他者と協調しながらアイディアを実現する基本姿勢。

## ゼミ選びの観点まとめ
- **向いている人**：センサやカメラ、スマートフォンから得られる**行動データ**を分析して人の状態や心を推定したい人。人流・移動・混雑・学習活動などの**時空間データ**を扱いたい人。センシング機器やダッシュボードを自分で作りたい人。AIやデータベースを使うだけでなく、独自のモデル・システムを設計・実装したい人。数理モデリングからセンサ・サーバまで手を動かして実装したい人。
- **キーワード**：行動データマイニング、サイバー・フィジカル空間、マインドフルネス・コンピューティング、時空間データ分析、センシング機器、ダッシュボード、可視化、フィードバック、AI・データベース、知識ベース、意味計算、未来創造プロジェクト、社会実装。
