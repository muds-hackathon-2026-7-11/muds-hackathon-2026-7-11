# ゼミ紹介資料の要約ドキュメント

各ゼミの配布資料（教員提供のPDF）を要約したドキュメント集。マッチ度診断・相談チャットの知識ソース（`seminars.knowledge`）や、人による比較検討に用いる。

## 構成
| パス | 用途 |
| --- | --- |
| `<ゼミ名>.md` | 人間が読む詳細版。研究テーマ・手法・機材・卒論例などを網羅。 |
| `knowledge/<ゼミ名>.md` | AI／DB投入用の簡潔な要約（`seminars.knowledge` 向け・約600〜800字）。 |
| `knowledge/teachers/<教員名>.md` | 合同ゼミで教員ごとに資料が分かれている場合の、教員単位の要約。 |

## 作成方針
- **配布資料に記載された事実のみ**で作成し、資料に無い情報は推測・補完・創作していない。
- ゼミ選び／マッチングに不要な情報（連絡先・URL・提携先ロゴ・詳細な書誌情報など）は除去している。教員の経歴は、ゼミ選びの判断材料になる範囲で人間用の詳細版にのみ記載し、`knowledge/` 側には含めない。
- 資料が改訂された際、**新しい資料から消えた情報でもゼミ選びに有用なものは残す**（どの版に基づくかを各ファイルの「出典」と冒頭の注記で明示する）。旧版PDFは `<名前>_old.pdf` として残す。
- 元PDFは私有資料のため `/.private/kyouin_siryou/` にあり、リポジトリには含めない。

## 更新方法
資料が改訂されたら、詳細版と `knowledge/` の両方を更新すること。`knowledge/` を変更した場合は、DBへの反映が別途必要:

```sh
make import-seminar-knowledge   # docs/seminars/knowledge/*.md を seminars.knowledge に投入
```

投入するまでマッチ度診断・相談チャットの回答は古い内容のままになる。また投入するとゼミ内容のハッシュが変わるため、`match_evaluations` の既存キャッシュが無効化され、学生の初回アクセス時にLLMで再計算される。
