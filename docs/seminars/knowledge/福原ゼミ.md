# 福原ゼミ（データサイエンス学科・福原義久）

「ビジネスマーケティング／IoT・ロボティクス プロジェクト」。担当の福原義久教員はフルスタックエンジニアで、機械学習・深層学習の講義を担当し、スタートアップを立ち上げて経営（AIトレーニングマシンを開発）。

## 研究分野・テーマ
- IoT・ロボティクス（IoTガジェットクリエイション）と、ビジネスマーケティング（ビジネスモデル構築）の2本柱。
- 上記に当てはまらないテーマも制約なく自由に研究可能。「自分が面白いと感じるテーマを見つける」「ユーザーも共感できる成果物を目指す」を重視。
- 研究テーママップでは「基礎研究↔社会的応用」「理論・手法↔応用・実践」の2軸上に、自然言語処理・推薦システム、画像認識・深層学習・画像生成、数理最適化・時系列解析・統計学習・強化学習、医療データ解析・都市データ分析・交通移動分析・スポーツ分析、機械学習の理論・ロボティクスなど幅広いテーマが分布する。テーマは学生により様々で、年度ごとに変わり続けている。

## 手法・使用技術
- IoTデバイス（Raspberry Pi、Arduino）、各種センサー・カメラ・アクチュエータ、スマートロボットカーなどの組み合わせによる問題解決。
- 機械学習・深層学習・深層強化学習、物体検出、画像・音・センサーデータの分析、自然言語処理・大規模言語モデル、Webサービス開発。

## 活動内容・身につくスキル
- 作りたいモノ／解決したいことに対し、どのデバイスを使い・どう実装するかの技術指導。ガジェットやWebサービスのプロトタイプ作成をサポート。
- 成果物目標：IoT・ロボティクス系は論文・特許、ビジネス系はピッチコンテスト・ビジネスアイデアコンテスト。

## 過去の研究テーマ・実績
- 例：脳波センサーによるIoT/ロボット操作、歌詞・楽曲に連動したステージ照明制御、機械学習によるスポーツ動作分析、空間の印象に基づく香り／アロマのレコメンド、個人の顔に合わせたメイクアップ手法の提案、医学用画像データベースの分析、F1のレース戦略、ボードゲームAI など。
- 卒業論文・学会発表の実績が豊富。情報処理学会全国大会、エンタテインメントコンピューティングシンポジウム、DEIM、FIT、国際会議 IIAI 等での発表多数で、学生奨励賞・学生プレゼンテーション賞の受賞歴もある。緑内障分類に関する研究は IEEE Access（2026年）に国際ジャーナル論文として掲載された。
