# 石橋・槌屋ゼミ（データサイエンス学部・石橋直樹／槌屋洋亮）

「未来創造プロジェクト／ビジネスマーケティングプロジェクト "Governance Design"」。ITを活用して社会課題を解決するため、Web環境でのモノ作り（開発）から実社会での運用・実験・起業までを一貫して取り組む。加えて槌屋教員が「Fabulous Fabrication Lab Ariake」を主宰し、3Dプリンティング・電子工作によるデジタルファブリケーションを扱う。

## 研究分野・テーマ
- Governance Design＝政治・経済・社会に対する工学的働きかけ。新しい仕組み・枠組み(System)の設計(Design)・構築(Implementation)・運用(Application)と、実験(Experimentation)・評価(Evaluation)を伴う一連のプロセス。
- テーマは「ITを活用した社会課題解決の検討」。SDGsに代表される国際的な社会課題を、WebやITの活用で解決する余地を探る。参考事例はCO2free.jp Project、MIKA Family、Artizon Museumなど。
- 槌屋研究室は「愉快なものづくり（Fabulous Fabrication）」をモットーに「（ほぼ）なんでもつくる技術（Digital Fabrication）」を追求。身の回りの困りごとから社会課題までを自由な発想で解き、知見をオープンに共有する。2026年後期から本格的な活動を開始予定。

## 手法・使用技術
- Web環境におけるモノ作り。クライアント側：HTML／CSS／JavaScript、iOS／Android。サーバ側：Perl・Ruby・C・Python／Java(JSP)／PHP／Pythonフレームワーク。データ保持：PostgreSQL／MySQL／NoSQL。サーバOS：Windows／macOS／Linux。
- デジタルファブリケーション：3D Design、3D Printing & Milling、Physical Computing、Electronics Design。Autodesk Fusion、Prusa Core One（3Dプリンタ）、MicroPython、Raspberry Pi Pico を使用。制作事例は3Dプリンティングを用いたシルクスクリーン、自作ペンプロッタ、自作顕微鏡、動的に絵画を切り替えるアートフレームなど。

## 活動内容・身につくこと
- Webはヒトとヒト・モノ・コトを繋ぐ媒体（SNS、E-Commerce、IoT、Museum、e-Learning、Game、Crowd Funding 等）。作り方の習得に加え、「ヒトと何をどう繋ぐのか?」というアイディアの設定を重視。
- 2026年後期は、希望者を対象に3Dプリンティングと電子工作のトレーニングを実施し、自分が作りたいものを作る。
- 期待されるOutput：サービス開発、実社会での運用・実験、起業。作った知見はドキュメント化やワークショップを通じて共有する。

## 担当教員
- 石橋直樹：博士(政策・メディア)、武蔵野大学データサイエンス学部教授、株式会社Governance Design Laboratory代表取締役。データベース／マルチデータベース／マルチメディアシステムの研究開発に従事。
- 槌屋洋亮：Fabulous Fabrication Lab Ariake を主宰。キーワードはDigital Fabrication、Rapid Prototyping、3D Design、Physical Computing、Open Source Hardware/Software。
