# 清木・林ゼミ（データサイエンス学科・AI＆データベース研究室 / AIDBL）

「AI・データベース研究室（AI & Database Lab, AIDBL）」。サイバー・フィジカル空間における「行動の理解」「心の推定」「環境創出」のための行動データマイニング研究を行う。担当は清木 康（教授）・林 康弘（准教授）の2名。武蔵野大学有明キャンパス。

## 研究分野・テーマ
- 人間の行動（移動→滞在→活動）には目的・関心・感情・身体状態・周囲の環境が表れる。センサ・カメラ・スマートフォン・情報システムから得られる行動データを分析して行動を理解し、背景にある心や状態を推定する。分析・推定結果を人間や環境へフィードバックし、より良い自然環境・社会環境・バーチャル空間・教育／学習環境を創り出す。
- 研究の4つの柱（Pillars）：(1)マインドフルネス・コンピューティングに向けた行動データ分析（集中・緊張・疲労・関心・感情・習慣の推定と、気づき・振り返り・行動変容の支援）、(2)より良い環境創出のための時空間データ分析（人流・移動・滞在・混雑・環境変化・学習活動・オンライン行動のパターン発見）、(3)センシング機器とダッシュボードの研究開発、(4)AI・データベース分野の人材育成。
- 応用領域：自然、都市、モビリティ、エネルギー、観光、産業、福祉、職業、教育。屋外空間（街・陸地・海・宇宙）と屋内空間（自宅・オフィス・駅・空港・病院・キャンパス）の行動データを扱う。

## 手法・使用技術
- センシング（IoTデバイス・カメラ・ウェアラブルデバイス・GPS・QRコード）→ プロセッシング（マルチデータベース、マルチメディアデータベース、時空間データマイニング、AIアルゴリズム、意味計算、知識ベース）→ アクチュエーション（アプリ、ダッシュボード、可視化、MR、ロボット）を一体的に扱う。
- データベース・SQL、数学・統計・最適化による数理モデリングに加え、センサ・ネットワーク・サーバ・アクチュエータまでの実装を重視する。

## 活動内容・指導方針
- 1年次秋開始の「未来創造プロジェクト」で各自が研究テーマを設定し、設計・実装・評価・発表を反復してアイデアを実際に動作するシステムへ発展させる。4年間の計画は、1年次＝基礎構築とテーマ設定、2年次＝独自モデル開発とプロトタイピング、3年次＝モデル改良と学会発表、4年次＝卒業研究の論文化と社会実装の検討。
- AIやデータベースを利用するだけでなく、現実の問題を計算可能な形で捉えて独自のモデル・システムを設計・実装する姿勢を重視。目的・意味・概念を問い直す探究心と、データ科学・工学・社会科学・人文知を横断する学際的アプローチを求める。

## 教育・関連
- 学部科目例：データサイエンス学、データベースデザイン、人工知能テクノロジデプロイメント、Webエンジニアリングと社会、マルチメディア知識ベース、コース演習I（人工知能クリエーション）、人間・AI協調進化システム、AI社会の情報倫理。大学院にはデータサイエンス先端研究、マルチメディア知識ベース特論、サイバー・フィジカルシステム特論。
