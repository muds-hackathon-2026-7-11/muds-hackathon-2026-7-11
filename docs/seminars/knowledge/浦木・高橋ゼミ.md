# 浦木・高橋ゼミ（データサイエンス学部・浦木麻子／高橋雄介）

AIx{} Project 浦木・高橋研究室の「未来創造プロジェクト」。「データサイエンスの視点から人間の進化・存続に貢献」を掲げる合同ゼミ。自然現象を人間がデータ（離散値）として分析・議論する営みを人間の経験や知識の宝の山と捉え、データベースが保証する根拠にAIの創造性を適切に組み合わせることで、人間へ新しい行動支援を発信することを目指す。応募には書類審査と面接があり、入った後も年に数回の審査がある。

## 担当教員（専門）
- 浦木 麻子（准教授・博士（政策・メディア））：時系列データの意味的理解が専門。
- 高橋 雄介（准教授・博士（政策・メディア））：知識ベースとその応用、グロースハック、顧客開発、プロダクトデザインが専門。

## 研究分野・テーマ
- 研究テーマ（キーワード）：Semantic Data Scope／Database／Data Mining／Conceptual Modeling／Time-series Data Modeling／Semantic Data Modeling。
- 浦木テーマ：時系列データの意味的理解。人間が状況分析で行う「着目点の移動」「解像度のコントロール」といった人間らしい時系列データの意味的な理解・比較・気づきの機能プロセスのモデル化を模索し、応用分野を議論する。
- 高橋テーマ：データをプロダクト・グロースの行動指針（actionable metrics）として活用する。

## 活動内容・指導方針
- 研究活動とは、新しいアイディア・方法論・計算式を生み出し、社会に発信して広く使われるよう育てていく営み。新規性を学術的に深め、国内外での研究発表と社会実装を目指す。
- 「いつでもどこでも観察→小さなアイディアを思いつく→メモする」という毎日のルーティンを研究の柱とする。思いついたらいつでも教員に連絡してよい。
- 国内外の多様なバックグラウンドのメンバーが対等な立場で共通の研究テーマに挑む。門戸は高校生にも開かれており、意欲と継続力・誠実さがあれば年齢や居住地は問わない。MIDS（国際データサイエンス学部）から博士号取得まで進む道も想定。

## 求められること・活動形態
- 研究成果をプロトタイプや論文にとどめず、実際に使えるアプリケーションまで実装する意欲。ユーザー・顧客目線、使いやすく美しい製品へのこだわり、高い誠実さ、強い目的意識と執念が必須。AI×自分の専門領域の掛け合わせ、情報システムの設計・実装スキル、世界へ発信する意志が推奨される。
- 講義開講期間中の金曜13:00〜20:30が研究室のミーティング時間。月1〜2回20分程度の枠を予約し、有明キャンパス（オフライン）またはZoomで進捗共有と議論に参加する。金曜のミーティングに出るだけでは評価されず、Slack等で継続的に相談し自発的に研究を推進することが求められる。
