## Governance Design とは（石橋）
- **Governance Design ＝ 政治・経済・社会に対する工学的働きかけ**。
- すなわち、新しい仕組み・枠組み（System）の **設計（Design）・構築（Implementation）・運用（Application）**、そして **実験（Experimentation）と評価（Evaluation）** を伴う一連のプロセス。

### プロジェクトのテーマ：「ITを活用した社会課題解決の検討」
- 2000年代を振り返ると、日常生活の多くの行為を Web に置き換えることで産業構造が大きく変化した。
- Web は依然としてビジネスの場として重要であり、ますますの発展が予想される。
- 一方で、**SDGs に代表される多くの国際的な社会課題は、Web や IT の活用で解決を探れる余地がまだまだある**と考えられる。

### 参考事例（GDLプロジェクト）
CO2free.jp Project（2005）、mamenergy project（2006）、Lohas Classic（2006）、MYFESTO.JP（2007）、3nnp.jp（2007）、MIKA FAMILY（2009）、Artizon Museum（2020）、Artizon Museum Apps（2020）

### 学ぶこと：WWW 環境におけるモノ作り
「石橋組における学び」として、Web 環境における開発技術を扱う。

| レイヤ | 技術 |
| --- | --- |
| Client-side Program | HTML / CSS / JavaScript(AJAX, jQuery 等)、Objective-C(iOS) / Java(Android) |
| Server-side Program | CGI(Perl, Ruby, Shell Script, C, **Python**) / Java(JSP) / PHP / **Python Frameworks** 等 |
| Repository | File System / PostgreSQL / MySQL / NoSQL / etc. |
| Server OS | Windows / macOS / Linux（Redhat, Fedora, CentOS, Ubuntu 等） |

### 現在の Web Appli（アプリケーション）の役割
- **Web ＝ ヒトとヒト・モノ・コトを繋ぐ媒体**。起点は「ヒト（＝smartphone）」。
  - ヒト → **ヒト**：SNS、Recruiting など
  - ヒト → **モノ**：E-Commerce、IoT など
  - ヒト → **コト**：Museum、e-Learning、Game、Crowd Funding など
- キーメッセージ：**作り方を学ぶことは勿論大事。でも「ヒトと何をどう繋ぐのか?」というアイディアの設定がさらに大事。**

## 槌屋研究室：Fabulous Fabrication Lab Ariake(α)
- モットーは「**愉快なものづくり（Fabulous Fabrication）**」。「**（ほぼ）なんでもつくる技術（Digital Fabrication）**」を追求する研究室。
- 身の回りの困りごとから社会課題まで、自由な発想で面白く解き、その知見をオープンに世界へ向けて共有することを目指す。

### 活動の流れ
**Ideas**（Personal Needs / Social Issues）→ **Digital Fabrication**（3D Design、3D Printing & Milling／Physical Computing、Electronics Design）→ **Sharing**（Documentation、Workshop）
